Website privacy

This page covers this website only.

This site sets no cookies. It runs no analytics and no trackers. It has no forms, so there is nothing here for you to submit. It loads no third-party scripts and no external fonts — every file the page asks for comes from this domain.

Nothing you do on this site is recorded by Fernando Enterprise. There is no account, no sign-in, and no profile.

The host sees the request

The site is served by GitHub Pages. As with any web host, GitHub receives the requests your browser makes — which includes your IP address — and keeps server logs. That happens before anything on this site runs, and it is outside our control. GitHub describes what it collects in its own privacy statement:

  • GitHub General Privacy Statement docs.github.com

If you email us

If you write to support@fernandoenterprise.com, we have your message and your address, because that is how email works. We use them to answer you.

The apps are covered separately

An app has its own privacy policy, and this page does not describe it. For CA Hunt & Fish Guide, read:

  • CA Hunt & Fish Guide privacy policy How the app itself handles your data.
